# Weighted Edmonds' Blossom Algorithm

Реализация прямо-двойственного алгоритма Эдмондса для поиска **совершенного паросочетания минимального веса** в произвольном неориентированном графе. Алгоритм использует сжатие цветков и коррекцию двойственных переменных.

## Особенности

- Поддержка произвольных графов (не обязательно двудольных).
- Обработка нечётных циклов (цветков) с помощью сжатия и разжатия.
- Не работает на графах, где образуются вложенные цветки.
